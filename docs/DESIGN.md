# Floating Panda Dream Design

## MVP Pillars

- Immediate fun: one screen, one objective, no menu required.
- Clear toy feel: floating panda, bobbing motion, bright pickups, soft danger.
- Tiny scope: Python-only Panda3D project with no custom art pipeline.

## Core Loop

1. Move panda through the sky lane.
2. Collect candy and lantern rings.
3. Avoid drifting ghost clouds.
4. Build streaks for higher scores.
5. Survive until the timer ends, then restart for a better score.

## Future Ideas

- Panda skins and unlockable trails.
- Moving lantern paths.
- Boss cloud that chases the panda.
- Local high score save file.
- Controller support.
