# Floating Panda Dream Design

## Design Pillars

- Immediate fun: one screen, one objective, no menu required.
- Dream arcade density: the browser game should feel full of moving charms, hazards, rings, trails, and scenery.
- Clear toy feel: floating panda, bobbing motion, bright pickups, readable danger.
- GitHub Pages first: the static browser version is the primary playable game.
- Panda3D reference second: the Python version remains a simpler desktop reference and does not need one-to-one feature parity.

## Core Loop

1. Move panda through the sky lane.
2. Collect common goodies, rare charms, and powerups.
3. Chain lantern rings and object pickups to build streaks.
4. Use darts, dream bubbles, star magnets, and lullaby bells to manage hazards.
5. Survive until the timer ends, then restart for a better score and dream rank.

## Browser Object Mix

- Goodies: moon candy, star fruit, moon pearls, prism gems, lotus blooms, dream kites, comet crumbs.
- Powerups: dream bubbles, time charms, dash feathers, star magnets, lullaby bells.
- Hazards: storm bolts, sleepy pillows, ghost clouds, thorn spirals, eclipse shards, gravity knots.
- Scenery: layered ribbons, clouds, lanterns, petals, crystals, islands, stars, moon glow.

## Future Ideas

- Panda skins and unlockable trails.
- Moving lantern paths and ring patterns.
- Multi-stage dream map with score gates.
- Challenge modes with different object mixes.
- Controller support.
